# HOST//VECTOR

A functional React + TypeScript prototype for a biological host-pathogen-vector field observation workflow.

## Run locally

```powershell
npm install
npm run dev
```

Open the local URL shown by Vite. The prototype includes a centralized Biological Case, distinct image and human evidence, explainable verification statuses, assistance pathways, and chronological follow-up monitoring. Use **Load demonstration case** to explore the full workflow without real-world data.
